# HTTP Quest

A browser game for learning HTTP and REST over a movies and directors API. Eleven levels, each one has you build a real request (method, path, query, body). The server runs it, returns the real status code, and decides whether the level passed. Nothing is judged in the browser. Schema reference at `/schemas/`.

Yahel Hai and Sivan Gruner, assignment 3, web development course. Needs Node 20 or newer.

```bash
npm install
npm start
```

Then open http://localhost:3000. Use `PORT=4000 npm start` to change the port and `npm test` to run the tests.
